# DEUX COMPLICES — ART

**Generate the images below and save each one into this `art/` folder, using the exact filename given.** Eleven single images, then twelve guard portraits from one template.

That's the whole job. The prototype already looks for these files — no code changes are needed, and none should be made. Until a file exists its slot renders as a labelled dashed placeholder box, so anything still missing is obvious and harmless.

Each prompt is a **complete, self-contained block**. Use it as written — don't paraphrase it, shorten it, or merge it with another one.

---

## RULES THAT APPLY TO EVERYTHING HERE

**Style — strict classic ligne claire**, the Franco-Belgian comic album tradition of Hergé's *Tintin*. Uniform single-weight black ink outlines on every element, near and far. Completely flat, unmodulated colour fills. No gradients, no glow, no grain, no texture, no painterly rendering, no cross-hatching. Shadows are single flat shapes of one darker colour, never soft. Even, neutral daylight — except the three marked NIGHT.

**Palette.** Warm paper white `#F7F3EA` · pale sky blue `#CFE0EA` · Parisian stone cream `#E4DCCB` and `#D3C8B2` · zinc grey `#8E9AA0` · camel `#C9975B` · ochre `#D8A13A` · muted olive `#7C8560` · denim blue `#4A6B87` · black ink `#14161A` · near-black `#0F1218` and `#1B2029` for the night images.

Semantic colours, never violated: **gold `#C9A24B` = the player** · **red `#C1372E` = threat, only ever threat** · **orange `#F4511E` = brand, never threat.**

**No text in any image, ever.** Every piece of type in this prototype is set live in code. Signs, screens, labels, documents, badges and notes must all come out as blank flat shapes or abstract dash marks — never letterforms. Generated lettering is the most common reason to bin a result. Check every image for it.

**Likeness — these are rights constraints, not taste. Regenerate anything that breaks them.**
- **Assane / Omar Sy: CLEARED.** Full, flattering likeness, always heroic.
- **Benjamin / Antoine Gouy: NOT CLEARED.** On-model — build, hair, cardigan, vintage watch — but **his face must never be visible**. If you can read the face, the image is unusable.
- **Any detective figure: featureless silhouette.** No face, no features.

**Never invent a stand-in.** If an image can't be generated, leave that file missing and say so. A missing file renders as a clearly labelled placeholder; a blank or improvised PNG looks finished and ships to a client pitch.

**Cropping.** The app centre-crops each image to fit its slot, so keep everything essential inside the central 85% of the frame. Each prompt says this too.
